La fuente establece como núcleo de Madre un motor de transformación de contenidos que recibe una entrada y la atomiza en 6 formatos: artículo web/SEO, Reel de 60 segundos, podcast, carrusel de 8 diapositivas, newsletter y WhatsApp. También plantea Supabase, pgvector, Edge Functions, seguridad de API keys, flujo editorial con revisión humana, Editor Crítico, transcripción y almacenamiento/historial.

La Guía de Estilo define explícitamente este flujo y señala que Madre debe distinguir estados como borrador, en verificación, revisada, publicada y corregida.

PASO 1 — Definir qué estamos construyendo

Antes de escribir el prompt técnico, propongo fijar esta definición base:

MADRE es el sistema web editorial inteligente que transforma información, documentos, fuentes y hechos en conocimiento periodístico verificable y posteriormente lo atomiza en múltiples formatos de comunicación, manteniendo trazabilidad, control editorial humano, memoria documental y capacidad de publicación multicanal.

Esto nos permite evitar un error importante del prompt anterior: reducir Madre a “Motor de Contenidos IA”.

La nueva versión debería concebirlo como un sistema editorial completo, cuyo motor de IA es solamente uno de sus componentes.
